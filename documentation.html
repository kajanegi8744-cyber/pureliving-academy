Implementation rules

  • Do not send names, email addresses, phone numbers, addresses, passwords or other personally identifiable information to GA4.
  • Only mark business outcomes as key events/conversions; do not mark every interaction as a conversion.
  • For purchase deduplication, preserve a stable unique transaction ID and verify refresh/back/retry behavior.
  • GA4 key event import and direct Google Ads conversion tracking are different implementation paths. Avoid double-counting the same outcome.
  • Consent requirements and regional policies must be reviewed before production use.

GTM setup checklist

  1. Confirm correct container and environment.
  2. Create GA4 Google tag with the intended Measurement ID.
  3. Create Custom Event triggers for website dataLayer event names.
  4. Create Data Layer Variables for parameters.
  5. Map GA4 event parameters to variables.
  6. Preview success and failure paths.
  7. Publish only after review and consent checks.
  8. Verify GA4 DebugView and relevant Google Ads diagnostics.
