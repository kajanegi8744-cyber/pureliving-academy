Hands-on learning

GTM Practice Lab

Use these exercises alongside your actual Google Tag Manager account. This website pushes demo events to the browser dataLayer; it does not configure tags in GTM automatically.

Module 01

Tag, Trigger, Variable

Client brief: Track a PDF guide click.

Event: file_download

Parameters: file_name, file_extension, link_text, link_url, demo_mode.

Practice: Create a Custom Event trigger named CE - file_download, then a GA4 Event tag with the same event name.

Module 02

Custom Event Trigger

Client brief: Track a successful contact form.

Event: generate_lead

Practice: Submit the contact form with valid values; inspect dataLayer and compare it with an invalid submission.

Module 03

Click trigger choices

Just Links: link elements. All Elements: broader click elements. Use a custom event when the website has a stable dataLayer event.

Practice: Compare a click listener with the custom event push and avoid counting click-only as success.

Module 04

Page lifecycle events

Container Loaded: GTM container initialization event. DOM Ready: document DOM is parsed. Window Loaded: page load and dependent resources have completed.

Choose triggers based on when the required elements/data exist.

Module 05

Variables and parameters

Create Data Layer Variables using exact parameter keys such as file_name and form_name. Test values in Preview before mapping them into event parameters.

Module 06

Debugging exercise

Submit an invalid form, then a valid one. Check event timeline, Tags Fired/Not Fired, trigger conditions, parameter values, consent and duplicate firing.
