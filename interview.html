What is the difference between Tag, Trigger and Variable?

A Tag sends data or performs an action. A Trigger defines when the tag should fire. A Variable provides values used by tags and triggers.

Why is a submit click not always a lead?

The form may fail validation or the request may fail. Count a lead only after confirmed successful submission.

What is the difference between GTM Container ID and GA4 Measurement ID?

The GTM ID identifies a container that manages tags. The GA4 Measurement ID identifies a web data stream destination for GA4 events.

How would you debug missing GA4 events?

Check the correct GTM container and page, Preview connection, event occurrence, trigger conditions, variable values, tag firing, Measurement ID, consent, blockers and GA4 DebugView.

How do you prevent duplicate purchase tracking?

Use a stable unique transaction ID, fire only after successful order creation, guard repeated confirmation execution, and validate refresh/back/retry cases. Confirm the destination's deduplication behavior.

What does a file_download event prove?

Usually that a download link was clicked or download initiated. It does not prove the user opened or consumed the file.

Why might a GA4 event not appear as a Google Ads conversion?

Check account linking/import status, key event configuration, selected conversion action, consent, attribution eligibility, tag diagnostics, conversion settings and reporting delay.
