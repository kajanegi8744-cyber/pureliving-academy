Debug with evidence

GA4 Debugging Lab

1. GTM Preview

Connect Tag Assistant to the exact deployed URL. Check event timeline, variables, trigger conditions, Tags Fired and Tags Not Fired.

2. Check the Data Layer

Open browser developer tools → Console and run window.dataLayer. Verify event name and parameter values after the intended action.

3. GA4 DebugView

Confirm the correct web data stream and Measurement ID, that the GA4 event tag fires, and that consent/ad blockers do not prevent transmission. DebugView visibility can be delayed or affected by configuration.

4. Google Ads diagnosis

Confirm linking/import or direct Google Ads tag setup, Conversion ID/Label where applicable, Conversion Linker, primary/secondary setting, attribution window and reporting delay.

Important: A browser dataLayer push alone does not prove an event reached GA4 or Google Ads. Verify each stage separately.
